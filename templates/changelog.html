Changelog

All notable changes to this project.

v2.4.0 2024-10-15 Latest
Added
  • Real-time collaboration with presence indicators
  • Export to PDF with custom branding options
  • Keyboard shortcuts for all common actions (? to view)
Changed
  • Improved search performance by 3x for large workspaces
  • Updated sidebar navigation with collapsible sections
Fixed
  • Fixed timezone handling in recurring tasks
  • Resolved memory leak in real-time sync module
v2.3.0 2024-09-28 Breaking
Breaking Changes
  • API v1 endpoints deprecated, use /api/v2/*
  • Minimum Node.js version increased to 18.x
Migration Guide

Update your API calls to use the v2 endpoints. The response format remains compatible. See docs/migration-v2.md for details.

Added
  • SSO support via SAML 2.0 and OIDC
  • Audit logging for enterprise compliance
v2.2.1 2024-09-14
Fixed
  • Fixed crash when importing large CSV files (>10MB)
  • Corrected date picker behavior in Safari
  • Fixed notification delivery for @mentions
v2.2.0 2024-08-30
Added
  • Dark mode support across all views
  • Custom field types: Date, Number, Dropdown
  • Bulk edit mode for task management
Removed
  • Legacy calendar widget (replaced by new calendar view)
  • Deprecated task.legacy_id field from API
